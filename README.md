# Graphics Experiments

This workspace contains small graphics demos and templates.

Run a local server to view apps (recommended):

Python (quick):
```bash
cd "C:\Users\darre\Documents\graphics-experiments"
python -m http.server 8000
```

Or install `http-server` with npm:
```bash
npm install -g http-server
http-server -p 8000
```

Then open http://localhost:8000 in your browser and click "Open Applications List".

You can also open `index.html` directly for simple demos that don't use modules.
