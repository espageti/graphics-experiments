Deferred Shading Notes

This demo compares three ways to display the same animated cube scene.

Quad view

The G-buffer textures are shown as a debug layout: world position, encoded normals, and albedo.

Deferred shading

The geometry pass stores position, albedo, and normal data in textures. A fullscreen quad then reads those textures and calculates the lighting for each screen pixel.

Forward shading

Each cube is shaded directly while its geometry is rendered. The fragment shader receives the interpolated world position and normal from the vertex shader.

Controls

Use WASD to move the camera and the arrow keys to rotate it. Use the buttons in the upper-right to switch render modes.
